# Keyboard Shortcuts

| Action | macOS | Windows / Linux |
|---|---|---|
| **Undo** | `Cmd+Z` | `Ctrl+Z` |
| **Redo** | `Cmd+Shift+Z` | `Ctrl+Shift+Z` |
| **Save snapshot** | `Cmd+S` | `Ctrl+S` |
| **Toggle left panel** | `Cmd+B` | `Ctrl+B` |
| **Toggle middle panel** | `Cmd+J` | `Ctrl+J` |

Additional shortcuts may be added in future releases.

---

## Tips

- Undo/Redo history is **per sheet** — undoing on one sheet does not affect another.
- The undo stack is preserved as long as your browser session is active. Refreshing the page clears the history (but your last saved snapshot is unaffected).
- **Save** updates the snapshot you currently have open, in place. If no snapshot is open it asks for a name. See [Snapshots](../saving-sharing/snapshots.md#saving-a-snapshot).
- Save is not available when the server is deployed with read-only snapshot storage.
